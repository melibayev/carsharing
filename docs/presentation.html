Problem Statement

The Car Rental Gap in Uzbekistan

🏢

Traditional Car Rental Agencies

  • High prices — middlemen add 40–60% markup
  • Limited vehicle variety and availability
  • Complicated paper-based processes
  • No transparent pricing or reviews
🚗

Private Car Owners

  • Cars sit idle 90% of the time
  • No platform to safely monetize their asset
  • No trust mechanism between strangers

Driver's License

Front, back, and selfie with license required for renters

Admin Review Queue

Paginated admin queue — Pending → In Review → Approved/Rejected

🚗 Car Listing Verification

  • Insurance policy upload + expiry date
  • Technical inspection certificate
  • Tech passport (front + back)
  • GPS tracker photo (optional)
  • VIN OCR extraction — mismatch flagged
  • Admin approves: Draft → Listed

🛡 Fraud Prevention

  • Fraud risk score per user (adjustable)
  • Is-on-fraud-watchlist flag
  • Admin can ban users instantly
  • Rate limiting on all public endpoints
  • Idempotency key on payments
  • Cancellation count tracked per host

📋 Audit Trail

  • Every admin action logged to AuditLog
  • Tracks: entity type, old + new values
  • IP address + user agent recorded
  • Paginated admin audit log view
  • Actor email preserved even after deletion

⭐ Review System

  • Mutual reviews: guest reviews host & vice versa
  • 14-day review window after trip completion
  • Rating averages updated on Car and User
  • Reviewer role tracked (Guest / Host)
